# 05 评分与养成

> 《不烧心夜市挑战》策划案 · v0.1
> 上游：[04-出摊阶段](04-出摊阶段.md) ｜ 下游：[10-待确认项与假设](10-待确认项与假设.md)

两条反馈链：

- **日内**：昨日评分 → 今日客流（惩罚做错的事）
- **局内**：当日评分 → 三选一加成（奖励做对的事）
- **局外**：整轮经验 → 技能树与解锁（长期变强）

---

## 1. 评分的三个出口

```
当日评分 DailyScore
 ├→ 次日客流系数：决定第 d+1 天的基础客流
 ├→ 口碑 Reputation：跨日累积的展示型数值
 └→ 经验 EXP：整轮结束时汇总
```

评分是**唯一**能让玩家直观知道"今天做得好不好"的量。因此必须满足：结算时能看到每一项加减了多少分（可解释），且分数变化要在次日开盘时说清"因为昨天 X 分，今天客流 Y"。

---

## 2. 评分 → 次日客流

| 评分区间（100 制） | 次日客流系数 | 展示 |
|---|---|---|
| ≥ 85 | ×`[待定: 1.15]` | 好评如潮 |
| 70–84 | ×`[待定: 1.05]` | 生意不错 |
| 55–69 | ×`1.00` | 平平淡淡 |
| 40–54 | ×`[待定: 0.90]` | 有点冷清 |
| < 40 | ×`[待定: 0.75]` | 摊前无人 |

- 系数**不叠加**：只取最近一天的评分，避免负螺旋无限加深 [假设-13]。
- 首日无评分时用中性基准 55 分对应的 1.00。
- 口碑 `Reputation` 的写入：`口碑 += (评分 − 55) × 系数[待定]`，仅用于展示与成就，对客流的额外修正上限 `[待定: ±10%]`（防止双通道叠加失衡）。

---

## 3. 经验

```
单日经验 = 基础经验(天数) × (0.5 + 评分/100)
整轮经验 = Σ_7天 单日经验 + 完成奖励（7 天跑完必给）
```

- 即使 7 天都是低分，整轮经验也**必须**够点 1 个技能点 [假设-14]（防挫败）。
- 天数越高基础经验越高（后期风险大、回报大）。
- 经验在 `RUN_SETTLE` 一次性结算，局内不显示具体数字，只显示"本轮获得经验"。

---

## 4. 每日加成（局内，三选一）

结算界面弹出 **3 张** 加成卡，玩家选 1 张，立刻生效且**本局永久**：

| 池子 | 示例 | 效果口径 |
|---|---|---|
| 扩建 | 台面 +`[待定]` 格 / 储存 +`[待定]` 格 | 直接加容量 |
| 效率 | 备货/备餐时间 +`[待定]` 分钟；某类加工耗时 −`[待定]`% | 改时间预算 |
| 省钱 | 采购货款 −`[待定]`%；运费 −`[待定]`% | 改成本 |
| 产能 | 某厨具 +1 工位；出餐时间 −`[待定]`% | 改出摊吞吐 |
| 风味 | 风味衰减 −`[待定]`%；储存格内成品衰减豁免 | 救"预加工"流派 |
| 客流 | 满意度 +`[待定]`；某属性需求 +`[待定]`% | 改需求端 |
| 词条 | 指定词条初始层数 +`[待定]`；某属性上架门槛 −1 款 | 直接强化构筑 —— **稀有** |

规则：

1. 三张卡**必须来自不同池子**，避免出现"三张都是 +1 格"的无聊局面。
2. 稀有池（词条类）出现权重 `[待定: 低]`，但可以做出"构筑爆发"的关键日。
3. 卡面必须写清楚"选了之后今天/后面几天怎么变"，不给模糊描述。

---

## 5. 局外养成：技能树

三支分支，每支 `[待定: 5]` 级，逐级解锁：

| 分支 | 定位 | 示例节点 |
|---|---|---|
| **效率**（EFF） | 省时间、省动作 | 备货行动耗时 −X%；备餐升阶耗时 −X%；开局额外 `[待定]` 分钟 |
| **容量**（CAP） | 摊子更大 | 初始台面 +X 格；初始储存 +X 格；开局自带厨具 |
| **风味**（FLV） | 卖得更贵、掉得更慢 | 风味衰减 −X%；风味档判定阈值放宽；售价 +X% |

规则：

- 技能点是**永久**的，跨轮累积。
- 每支分支的节点有前置依赖（线性解锁，不做自由树 —— 自由树在 7 天短局里来不及体现差异）。
- 每轮开局可选择"继承配方"：已解锁的菜谱与厨具在一开始就可用。

---

## 6. 解锁系统

| 解锁对象 | 途径 | 影响 |
|---|---|---|
| 厨具 | 经验购买 / 成就 | 解锁新的餐品线（锅→炸锅→制冰机…） |
| 菜谱（餐品） | 经验购买 / 局内达成条件（如某餐品单日售出 X 份） | 扩展构筑空间 |
| 属性/词条 | 随菜谱自然出现 | 通常不透支解锁，避免一开始就有 6 条词条 |
| 摊位皮肤 / 装饰 | 成就 | 纯表现 |

- 玩家一开始只有 `[待定: 8]` 款餐品可用，7 天一轮打完通常在 12~16 款之间 —— 每轮都能玩出新构筑。
- 解锁成本必须让第 2、3 轮有明显进展感：一轮经验 ≈ 能买 1~2 个新菜谱或 1 个技能点。

---

## 7. 一局的节奏目标（给数值的验收标准）

| 期望 | 目标值 |
|---|---|
| 单轮时长 | `[待定: 25~40]` 分钟现实时间（7 天 × 约 4 分钟） |
| 首轮通关率（跑完 7 天不退出） | ≥ `[待定: 80%]` |
| 玩家第几轮开始主动做多词条构筑 | 第 2 轮 |
| 全部内容解锁所需轮数 | `[待定: 8~12]` 轮 |
| 单轮第 7 天的评分应显著高于第 1 天 | 是（成长可感知） |
