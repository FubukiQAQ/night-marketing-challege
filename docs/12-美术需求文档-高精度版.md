# 不烧心夜市挑战 · 美术需求文档（高精度版）

> 版本 v2.0｜2026-11-04｜HD 精细像素｜Web / 移动端横屏｜PixiJS + DOM
> 内容规模：82 餐品、126 食材、13 厨具、12 标签、12 词条、8 共鸣。

## 1. 视觉目标

- 中式夜市的写实光色、精细像素材质、明确的小尺寸辨识度。
- 暗部保留墙体、砖缝、棚布、路面等层次，不使用纯黑遮蔽未完成细节。
- 暖灯照亮摊位与食物，冷色环境光分离远景；食物与营业反馈是最高视觉优先级。
- 所有业务图标、食材、餐品、状态及控件的基础绘制尺寸不得低于 **32×32 px**。粒子、灯光与装饰细节除外。
- 禁止赛博朋克紫粉主调、照片纹理、矢量平滑感、抗锯齿像素边缘、模糊滤镜、廉价外发光。

## 2. 技术规范

### 2.1 画布与网格

| 项目 | 要求 |
|---|---|
| 场景基准分辨率 | **960×540，16:9** |
| 显示倍率 | ×2＝1920×1080；其他窗口使用 letterbox |
| 基础网格 | 16×16；主体构图以 32×32 为最小模块 |
| 定位 | 所有像素资产对齐整数坐标，禁止亚像素定位 |
| 采样 | 最近邻；图集保留 1x 原始尺寸 |
| 像素密度 | 同一资产内像素颗粒一致，禁止混入高清平滑笔触 |
| 描边 | 主体外轮廓 1~2px；内部结构线 1px；不使用纯黑粗描边包死细节 |

### 2.2 标准尺寸

| 资产 | 尺寸 |
|---|---|
| 食材图标 | **32×32** |
| 餐品图标 | **48×48**；复杂餐品使用 **64×64** |
| 标签、词条、状态、QTE 图标 | **32×32** |
| 共鸣图标 | **48×48** |

### 2.3 色彩与材质

- 基础环境色板 **32 色以内**；单个普通 sprite 使用 **12~24 色**，特殊立绘不超过 **64 色**。
- 每类材质至少区分：固有色、暗部、中间调、受光面、高光，不得仅靠两阶色块交付。
- 金属：窄而硬的冷色高光；陶瓷：宽而柔的暖白高光；油脂：少量高亮像素；布料：低对比织纹；竹木：顺纹色带。
- 食材必须表现切面、表皮、汁液或颗粒中的至少两项，不得只画单色色块。
- 夜色基准：最深色 `#080C12`，环境暗部 `#101927`、`#182638`，冷反光 `#42627A`。
- 灯光基准：灯芯 `#FFF0C7`，主光 `#FFD080`，边缘光 `#F29A45`，炭火 `#D9572B`。
- 金钱 `#FFC93C`，危险 `#FF5C7A`，正文 `#F7EEDD`。
- 光色可以改变固有色，但不得使标签色、危险色和金钱色失去区分。

### 2.5 动画

| 项目 | 要求 |
|---|---|
| 常规循环 | 8~12fps，4~8 帧 |
| 出餐、QTE、升档 | 12~16fps，6~12 帧 |
| 待机和环境 | 2~6 帧，错相循环，禁止整屏同步闪烁 |
| 位移、透明度 | 程序 tween； sprite 禁止非整数缩放与任意角旋转 |
| 循环 | 首尾无缝，无明显跳点、闪边和材质漂移 |
| 工作识别 | 厨具 idle 与 work 必须在静帧下可区分 |

### 2.6 图集与文件

- PNG-32 交付源文件；可另交索引色优化版。禁止 JPEG。
- 图集按 `scene / food / ing / utensil / char / ico / ui / fx` 分页，单页不超过 4096×4096。
- TexturePacker JSON Hash；每帧 extrude 2px、padding 2px，禁止颜色渗边。
- 阴影独立交付，不烘焙进可复用 sprite。
- 命名：`类别_主体_动作_变体_序号.png`，全小写。
- 每类资产同时提交：独立 PNG、图集、JSON、总览图、源文件。
- 源文件按层保留：轮廓、固有色、明暗、材质、高光、特效；不得只交不可编辑的合并图。

## 3. 图标与食物

### 3.1 通用要求

- 统一左上方主光，右下方冷色反光；光源不得逐张改变。
- 图标主体占画布 75%~88%，禁止缩在画布中央或顶满边界。
- 允许 1~2px 深色局部轮廓，不使用统一白描边覆盖所有图标。
- 同屏小尺寸下先识别类别，再识别具体物件；关键特征不少于 3 个。
- 图标不烘焙中文、数字、阴影和动态光效。

### 3.2 食材（126）

- 32×32，每个食材绘制主体、切面或局部、类别特征细节。
- 叶菜区分叶脉和叶缘；肉类区分肥瘦与皮；水产区分鳞、壳、触须；豆制品区分孔隙与表皮；调味品使用容器形态与内容物双重识别。
- 11 类分别建立色彩倾向，但同类不得只靠换色区分。
- 每 16 个同类食材制作一张无文字随机识别表；另外提交 32px 原尺寸及 24px 缩图。
- 文件名使用配表 ID，禁止以中文名作为唯一文件名。

### 3.3 餐品（82）

- 标准 48×48；汤粉、烤串组合、拼盘等复杂餐品使用 64×64。
- 采用“容器＋主食体＋配料＋标志性点缀＋材质高光”结构。
- 至少交付 **48 个可复用元件**：碗、深盘、浅盘、杯、瓶、纸包、签、汤底、饭团、面体、肉块、炸物、蔬菜、冰品及撒料。
- 酸辣粉、螺蛳粉、麻辣烫不得共用仅换色的主体：分别突出红薯粉与红油花生、酸笋与腐竹、竹签与混合食材。
- 每道菜附一行视觉锚点说明，标明容器、主体轮廓、三个识别细节和专属点缀。
- 先完成 8 道样板：汤粉、米饭、炸物、烤串、卤味、凉菜、热饮、冰甜品各 1 道；通过后批量制作。
- 交付正常、售罄灰化、未解锁剪影三种状态；后两种由程序处理时也需提供规范样例。

### 3.4 厨具（13）

- 64×64；汤桶、冰柜、大型蒸屉可用 96×96。
- 每件提供：idle 1 帧、work 6 帧、台面视图 1 张、缺货/故障标记规范 1 张。
- 锅：锅体厚度、金属边、汤汁与蒸汽；炸锅：油面、气泡、金属网篮；烤炉：炭层、烤网、火星；铁板：油膜、刮刀、热蒸汽。
- 蒸笼：竹编、叠层、凝结水；汤桶：高桶、盖、汤勺；卤锅：酱色液面、香料包、厚重锅沿。
- 制冰机：舱门、冰块、冷色状态灯；榨汁机：杯体、液面、刀座；豆浆机：机身、壶口、白浆；搅拌机：高杯、旋涡、底座。
- 电饭煲：开盖结构、内胆、蒸汽与保温灯；冰柜：玻璃门、内部层架、冷白灯。
- 工作状态同时使用动作和物质变化，不得仅加一团通用蒸汽。

### 3.5 词条、共鸣与状态

- 12 词条均为 32×32，具象物件、独立构图；右下角留 10×10 空角供档位叠加。
- 速度为王：锅与速度线；吃饱了：冒尖米饭；好辣：喷火辣椒；现做饮品：雪克杯；现做的不烧心：锅铲与火；冰冰冰：叠冰与雪花。
- 滋滋响：油泡与炸篮；干杯：碰杯；炭火气：炭块与烟；热乎：汤碗与三缕蒸汽；甜上头：糖霜点心；老卤：卤锅与香料包。
- 8 共鸣图标 48×48：两个物件、组合连接结构、双色光弧；光弧不得遮住物件。
- 需求气泡、等待、催促、满意、愤怒、缺货、差评、连击、金钱、时间、空间、储存等图标均为 32×32。
- 四类 QTE 图标 32×32，另交操作区底图与成功/失败回执。

## 4. UI 素材

- UI 由 DOM 排版；仅交付九宫格、控件、图标及局部装饰，不交付整屏文字图。
- 设计基准 1920×1080；最小触控区 44×44 CSS px。
- 面板边距 8/16/24/32；圆角 0、2、4px；禁止大圆角与玻璃拟态。
- 面板底至少包含外框、内沿、底纹、受光边四层；暗底上保持清晰边界。

| 素材 | 要求 |

| 深色、浅色面板 | 64×64 九宫格，边切 16px |
| 按钮 | 48×48 九宫格；主/次/危险/禁用 × 默认/悬停/按下/焦点 |
| 卡片 | 64×64 九宫格，普通/高亮/选中/锁定四态 |
| 标签页 | 64×32，开关两态 |
| 滑块、滚动条、进度条 | 32px 高度源图，轨道与滑块分离 |
| 复选框、单选框 | 32×32，含焦点态 |
| 关闭、箭头、更多、趋势 | 32×32 |
| 星级、评分 | 32×32 |
| 提示框、抽屉、横幅、缎带 | 64×64 或可平铺结构 |
| 进度点 | 16×16，实心/空心/高亮/脆弱四态 |

- 数字使用等宽像素数字，提供 16/24/32/48px 四套，含 `0-9 + - ¥ : / %`。
- 中文正文由程序使用思源黑体或霞鹜文楷渲染；图片内不得烘焙中文。
- 顶栏、备货、备餐、出摊、QTE、结算、技能树所需控件全部按实际状态交付，不以单一静态按钮替代状态组。

## 5. 场景与背景

### 5.1 分层与精细度

| 层 | 尺寸 | 内容 |
|---|---|---|
| far | 1152×540 | 建筑、窗户、屋顶、电线、天空、远景招牌 |
| mid | 1248×540 | 邻摊、棚架、桌椅、行人、远处车辆 |
| ground | 1056×540 | 路面、砖缝、油污、积水、投影承接 |
| near | 960×540 | 主摊、近景道具、前景遮挡 |
| light | 960×540 | 光源遮罩、局部光斑、反光 |

- 每层可独立修改；不得把远景、中景和灯光合并成单张背景。
- 背景不是剪影填充：可见区域必须包含建筑结构、使用痕迹、材质变化、生活杂物和局部叙事。
- 远景细节对比度低于主摊 40%以上；中景低于主摊 20%以上；禁止高亮背景抢走餐品和 UI 焦点。
- 每个场景至少包含：3 种建筑或棚架材质、5 组生活杂物、3 处使用磨损、2 处环境反光、1 个区域性地标。
- 砖缝、木纹、铁皮折边、织物纹理按透视与结构绘制，不使用均匀噪点冒充精细度。
- 地面反光与光源位置一致；积水有边缘、断续反射和遮挡，不使用整块镜像。
- 预留 UI 安全区，背景高对比细节不得集中在文字和数字下方。

### 5.2 批发市场

- 冷白晨光和铁皮棚顶漏光，整体明亮但保留冷暖分区。
- 包含钢架、波纹铁皮、水泥柱、卷帘门、货车尾板、泡沫箱、塑料筐、纸箱、价牌、捆扎带、地面水迹。
- 筐与箱至少 6 种堆叠组合；蔬菜、肉禽、水产区域具有不同色彩和物件。
- 交付 far/mid/ground/near/light 五层，另交 6 组可摆道具、4 个挑货人姿态。
- 提供正常营业、物流受阻两种中景变体。

### 5.3 备餐摊位

- 傍晚天空由低饱和橙过渡至靛蓝，摊车尚未完全点亮。
- 台面包含砧板、刀具、待切食材、调料罐、塑料布、收纳箱、抹布、水盆；物件排列符合备餐操作关系。
- 交付五层背景、3 个时段色光版本、8 组台面散件、塑料布掀起/放下两态。

### 5.4 夜市街

- 主场景，分别制作暗版、成长版、繁盛版三套完整光色状态，不仅改变整体亮度。
- 暗版：主摊暖光、少量邻摊灯光、完整暗部结构。
- 成长版：新增邻摊窗口、招牌、顾客活动区和更多反射，主摊仍为最亮区域。
- 繁盛版：街道纵深、灯串、人群和店铺层次完整，保持视觉动线清晰。
- 必须绘制路面修补、油污、塑料凳、折叠桌、煤气管道、电缆、招牌支架、门洞、空调外机等细节。
- 每版交付五层；三层中景共用结构可复用，但灯光和人群不得只做透明度高低的区别。
- 雨：独立雨线、檐口滴水、湿地反射、雨棚积水四层。
- 雾：分层 dither 遮罩和远景降对比版本，不使用高斯模糊。
- 竞争：对面摊位独立模块，含车体、招牌、雨棚、灯和桌椅。

### 5.5 摊车模块

| 模块 | 尺寸/要求 |
|---|---|
| 车体基座 | 384×160，车架、柜门、轮子、焊点、磨损分层 |
| 台面标准格 | 64×64，可无缝平铺 |
| 台面左右收边 | 64×64，各 1 |
| 雨棚 | 384×96，红白蓝条纹，放下/撩起两态，布料褶皱完整 |
| 招牌 | 192×64，空白，含金属框与固定件 |
| 菜单牌 | 96×128，空白，含悬挂结构 |
| 灯串单元 | 96×32，6 颗灯泡，可横向无缝拼接 |
| 塑料凳 | 32×48，红/蓝/白 |
| 燃气罐 | 48×80，罐体、阀门、管线 |
| 收款牌 | 32×48，牌面留白 |
| 水桶、垃圾桶 | 48×48，结构不同 |
| 主照明灯 | 64×64，灯具与光效分离 |
| 置物架、收纳箱、调料架 | 64×64 起，各至少 2 变体 |

- 摊车至少包含金属、漆面、塑料、布料四种材质。
- 拼接处不得出现断线、重复高光、透视不一致和像素密度变化。
- 灯串提供 on/off/flash 三态；发光光斑独立；共鸣弧段 32×32，可拼接。

## 6. 角色

### 6.1 摊主

- 64×80，侧后三分之四视角，头身比例统一，围裙、衣服褶皱、手部动作清楚。
- 动作：待机 4 帧、颠勺 8 帧、递餐 6 帧、搬货 6 帧、擦汗 4 帧。
- 3 套配色；每套保持明暗层数一致，不仅整体替换色相。
- 手持物与身体分层，方便替换厨具和餐品。

### 6.2 普通顾客（8 类）

- 48×64；每类具备轮廓、服装、随身物三重识别。
- 每类动作：行走 6 帧、等待 4 帧、催促 4 帧、满意 4 帧、离开 6 帧。
- 表情头部贴片 32×32：平静、期待、着急、不满、满意，各 1。
- 学生：校服与双肩包；加班族：松领带、衬衫、眼镜；外卖员：头盔、保温箱；情侣：两组互补轮廓与互动动作。
- 大爷：白背心、蒲扇；小孩：较矮身形与圆头；夜跑者：运动装、耳机、反光条；醉汉：不稳定重心与面部红晕。
- 情侣除单人资产外，另交等待和满意两组组合动作。

### 6.3 特殊顾客（5）

- 160×160 半身立绘，允许 64 色；必须有服饰材质、手部道具、清晰表情与冷暖光层次。
- 美食博主：手机、补光灯、稳定器；金牌外卖员：头盔、保温箱、汗珠；炸货老饕：体型、毛巾、油渍细节；挑剔老人：眼镜、手杖、皱眉；大胃王：瘦高体型、叠碗。
- 每人交满意/普通/不满三态立绘、64×64 头像、QTE 入场动作 6 帧。

### 6.4 群演

- 夜市场景 12 个姿态，48×64；不得只交纯黑剪影，至少有低对比服装和冷色轮廓光。
- 行走 4 帧、站立 1 帧；分成 3 个明度层级供纵深摆放。
- 备货场景挑货人 4 个，48×64，各 4 帧。

## 7. 特效

- 粒子基础单元：dot 8×8、spark 16×16、smoke 32×32、oil 16×16；其余业务特效从 32×32 起。
- 蒸汽至少 3 套形态：汤蒸汽、炸锅热气、冷气；不得共用一张换色。
- 油花、火星、水滴、冰晶、蒸汽均提供 4~8 帧循环或序列。
- 光斑使用离散色带和有序 dither，禁止平滑径向渐变和模糊滤镜。
- 光斑、反射、粒子、拖尾、星爆、横幅分层交付。
- 出餐拖尾、升档星爆、共鸣弧、灯串闪白、印章落下均提供完整序列与首帧/末帧说明。
- 同屏粒子不超过 160；单屏主要动态光源不超过 8，背景静态光源不占动态预算。
