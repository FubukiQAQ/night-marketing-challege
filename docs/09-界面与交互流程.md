# 09 界面与交互流程

> 《不烧心夜市挑战》策划案 · v0.1
> 上游：[03](03-备餐阶段.md)、[04](04-出摊阶段.md) ｜ 关联：[08](08-技术实现-Web.md)

本章定义玩家看到什么、能点哪里。**Web 项目，默认桌面横屏优先，兼容移动端横屏**。

---

## 1. 界面地图

```
标题页
 └→ 局外面板（技能树 / 解锁 / 图鉴 / 开始新的一轮）
      └→ 第 d 天
           ├→ 备货界面 STOCK ──┐
           ├→ 备餐界面 PREP  ──┤（阶段顶栏常驻）
           ├→ 出摊界面 SELL  ──┤
           ├→ 结算界面 SETTLE ─┘（含加成三选一）
           └→ 打烊 → 次日 or 轮结算 → 局外面板
```

### 1.1 常驻顶栏（所有局内界面共用）

从左到右：`第 3/7 天` ｜ `现金 ¥128` ｜ 当前阶段名 + 时间条 `剩余 142 分钟`（出摊时显示 `营业中 00:37`）｜ `菜单` ｜ `设置`

- 时间条是**最重要的一条 UI**：它把"我还能做多少事"可视化。出摊阶段换成现金流进度（当前营业额 / 昨日营业额）。
- 现金变化用短促的 `+¥`/`−¥` 飘字，涨绿跌红，同时提供 `+`/`−` 符号（不只靠颜色）。

## 2. 备货界面

```
┌───────────────────────────────────────────────────────────┐
│ 顶栏：第 2/7 天 · ¥150 · 备货 · ▓▓▓▓▓▓░░░░ 剩余 210 分钟   │
├──────────────────────────────┬────────────────────────────┤
│ 供应商列表（3~5 张卡）        │ 今日行情 / 昨日复盘抽屉     │
│ ┌──────────┐ ┌──────────┐    │  · 昨日销量榜              │
│ │老张蔬菜  │ │海鲜老李  │    │  · 缺货告警 ★              │
│ │加价 +5%  │ │加价 +18% │    │  · 剩货与风味档            │
│ │营业中    │ │⚠ 物流受阻│    │  · 建议进货量（可一键填）   │
│ └──────────┘ └──────────┘    │                            │
│                              │ 今日事件                   │
│ 选中供应商 → 货架网格         │ ⚠ 老张蔬菜今日停业          │
│ 每种食材：图 / 名 / 价 / 库存 │ ⚡ 平台运费全免             │
│ [买 1][买 5][买 10]           │                            │
├──────────────────────────────┴────────────────────────────┤
│ 购物车 3 项 ¥46 · 占储存 6/12 格     [在线订货]  [去备餐 →] │
└───────────────────────────────────────────────────────────┘
```

交互要点：

| 项 | 规则 |
|---|---|
| 进店耗时 | 首次点击某供应商时弹出"步行 25 分钟"，确认后才展开货架 |
| 比价 | 鼠标悬停食材显示"基准价 ¥X，本家溢价 +Y%" |
| 超预算 | 加购按钮变灰并提示"现金不足，结算时会赊账"（若启用赊账） |
| 储存格满了 | 加购按钮灰掉，提示"储存格已满，需扩容或丢弃" |
| 一键补货 | 建议进货量旁的「照填」按钮，把建议量批量加入购物车 |
| 到货提醒 | 昨日在线订单到货时用横幅提示："昨天下单的 3 项已送达" |
| 结束阶段 | `去备餐 →` 二次确认："还有 210 分钟没用完" |

## 3. 备餐界面（核心） ★

这一屏的设计质量直接决定游戏好不好玩，因为玩家 70% 的思考发生在这里。

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：第 3/7 天 · ¥92 · 备餐 · ▓▓▓▓▓▓▓░░░ 剩余 180 分钟         │
├─────────────────────────┬─────────────────────────────────────┤
│ 餐品库（可上架）         │ 词条面板 ★                          │
│ [速食]方便面   空间1  ¥? │  速食  ●●●○○  3/5  速度为王 一档 ✓  │
│ [速食][魔鬼辣]火鸡面 …   │   ⤷ 再上架 2 款 → 全餐品出餐 −20%   │
│  … 可筛选 属性/厨具/空间 │  主食  ●●○○○  2/3  未激活           │
│                         │   ⤷ 再上架 1 款 → 吃饱了激活        │
│ ── 今日菜单（已上架）──  │  魔鬼辣 ●●●●○ 4/4  好辣！激活 ✓     │
│ 酸辣粉  ¥12  [−][+] 份  │  现做食品 ○○○○ 1/4   未激活          │
│ 炸鸡排  ¥10  [−][+] 份  │  现做饮品 ○○○○ 0/6   未激活          │
│ …                       │  凉菜   ○○○○ 0/6    未激活           │
├─────────────────────────┴─────────────────────────────────────┤
│ 排产区：食材 → 半成品 → 成品                                    │
│ 粉（熟半成品）×6    [升阶 → 成品] 耗时 12 分钟                 │
│ 汤（成品）×8        已就绪                                     │
├───────────────────────────────────────────────────────────────┤
│ 台面 8/10 格 ▓▓▓▓▓▓▓▓░░   储存 9/12 格 ▓▓▓▓▓▓▓▓▓░░░           │
│ [临时采购]                                    [出摊 →]         │
└───────────────────────────────────────────────────────────────┘
```

### 3.1 词条面板的硬性要求

- 每个属性一行，显示 `已上架款数 / 下一档门槛`，用实心点表示进度。
- 已激活的词条：绿色描边 + 效果全文（参数代入当前 `X`）。
- 未激活但**一步可达**的：黄色高亮 + `⤷ 再上架 N 款` 提示。这是引导核心。
- 已激活但**会因为下架而失效**的：显示为"脆弱"，悬停告知"下架 1 款将失去该词条"。
- 面板固定在右侧，**不允许折叠到二级菜单**。

### 3.2 上架/定价交互

| 操作 | 反馈 |
|---|---|
| 拖拽或点 `+` 上架 | 立即刷新词条面板（有 0.15s 的"叮"强调动画） |
| 上架后空间超限 | 拒绝并高亮超出的餐品，说明 `超出 2 格` |
| 上架后厨具缺失 | 允许上架但标红警告："无炸锅，只能卖已成品" |
| 改价 | 数字输入 + 上下箭头，旁边显示"昨日 ¥10 ↑"与预估客流影响 |
| 份数 | 只显示"当前可售份数"，来源 = 成品 + 可现场制作的半成品 |

### 3.3 排产区

- 按食材聚合显示，不按餐品（因为同一食材服务多个餐品）。
- 每个食材一行：`种类 · 当前阶段 · 数量 · [升阶按钮] · 预计耗时`。
- 升阶按钮上直接写代价：`升阶 12 分钟`，不让玩家去查表。
- 时间不足时按钮变灰，提示"时间不够（需 12 分钟，剩 8）"。
- 提供"自动排产"辅助按钮：按当前菜单与预计销量自动加工 `[待定: 是否做]`（会削弱策略深度，建议做成难度选项）。

## 4. 出摊界面

```
┌───────────────────────────────────────────────────────────────┐
│ 第 3/7 天 · 营业中 ▓▓▓▓▓▓▓▓▓▓░░░░ 00:37  │ 1x  2x │ ¥86    │
├───────────────────────────────────────────────────────────────┤
│  [PixiJS 舞台：摊位 + 锅/炸锅 + 排队顾客 + 出餐动画]           │
│   顾客头顶耐心条；出餐时餐品飞向顾客；成交飘 +¥12              │
├───────────────────────────────────────────────────────────────┤
│ 词条条  ★速度为王 一档 | 好辣！X=12 | 魔鬼辣 ▓▓▓░             │
│ 实时统计：成交 24 份 · 客诉 1 · 流失 3                          │
└───────────────────────────────────────────────────────────────┘
```

要求：

| 要素 | 要求 |
|---|---|
| 角色可读性 | 顾客用不同颜色/图标区分需求（辣/主食/饮品），并配文字气泡写"想吃什么" |
| 忙闲一眼可见 | 厨具冒气/冒火光表示在工作；队列长度用小人数量直观显示 |
| 出餐反馈 | 每份成交必须有"餐品飞过去 + 金额飘字 + 音效"，60 秒里这是唯一的持续正反馈 |
| 层数反馈 | 词条条上的 `X` 每次 +1 都滚动，并闪一下 |
| 加速 | 1x/2x 按钮常驻右上；切 2x 时舞台不降帧 |
| 暂停 | 允许暂停（Web 玩家会切标签页），暂停时遮罩 |

### 4.1 QTE 弹层

```
┌─────────────────────────────────┐
│  外卖员：快点！超时要赔钱了！    │
│  ┌───────────────────────────┐  │
│  │  ◉ 连点 2.5 秒      ⏱ ◐  │  │
│  │      [ 猛 击 ]             │  │
│  └───────────────────────────┘  │
│  成功 ¥+30 / 失败 −¥10          │
└─────────────────────────────────┘
```

- 弹层**局部**遮罩（不全屏黑），玩家仍能看到摊位在跑。
- 成功/失败必须在 0.5 秒内给出明确回执。
- 支持键鼠与触屏两套输入；触屏的判定区不小于 44×44 px。

## 5. 结算界面

顺序（可点击跳过整段）：

1. `营业额 ¥186` ← 从 0 滚动上去
2. 订单流水摘要（成交 X 份 / 客单价 / 流失 Y）
3. **词条贡献榜**：`好辣！触发了 14 次加购，多卖 ¥42`（让玩家看到构筑的价值）
4. 满意度与差评原因分类（缺货 X 次 / 太慢 Y 次 / 不新鲜 Z 次）
5. 当日评分 + 与昨日的对比箭头
6. **加成三选一**（3 张卡，必须来自不同池）
7. `进入第 4 天`

评分一定要解释得清 —— 玩家看到"我因为缺货扣了 12 分"，第二天才会去补库存。

## 6. 局外面板

- 技能树三支页签，节点显示等级与效果，未解锁的节点显示前置。
- 菜谱/厨具图鉴：已解锁的显示配方与最优出场次数，未解锁的显示解锁条件（提示"单日售出 20 份即可解锁"）。
- `开始下一轮` 按钮，旁边显示"将继承：技能 N 点、已解锁 M 个菜谱"。

## 7. 通用交互规范

| 项 | 规范 |
|---|---|
| 数值格式 | 金钱 `¥1,280`；时间 `142 分钟`；tick 不直接展示，出餐时间一律换算成"约 X 秒/X 分钟" |
| 空状态 | 每个列表都要有引导文案（"还没上架任何餐品 —— 从左边点 + 试试"） |
| 错误提示 | 说明"为什么不行 + 怎么才行"，不只说"无法操作" |
| 悬停 | 所有属性/词条/厨具图标悬停出 tooltip，含定义与影响 |
| 二次确认 | 只在不可逆操作上（结束阶段、丢弃剩货） |
| 键位 | `Space` = 继续/确认，`Esc` = 返回，`1/2/3` = 加成三选一 |
| 色盲 | 状态不能只靠颜色，必须配图标或文字（涨价 ↑、降价 ↓） |
| 字号 | 桌面 ≥14px；关键数字（现金、评分）≥20px |

## 8. 移动端（横屏）

| 项 | 调整 |
|---|---|
| 布局 | 备餐界面的"词条面板"改为底部抽屉（可上滑展开），因为右侧固定会挤没 |
| 拖拽 | 上架改为点按，不用拖拽 |
| QTE | 判定区加大；连点类降低目标次数 `[待定]` |
| 出摊舞台 | 逻辑分辨率 960×540，UI 缩放因子单独配置 |
| 存档 | 切后台即存 |

## 9. 新手引导

- 只在**第 1 天**用强引导（高亮 + 遮罩 + 一句说明），第 2-7 天用一次性提示。
- 第 3 天必须有一段**强制演出**：上架第 3 款速食的瞬间，"速度为王 激活"以全屏横幅出现，并让玩家看到出餐时间数字变小。
- 引导**不锁操作**（除第一天的第一次采购），避免玩家觉得被按住。
